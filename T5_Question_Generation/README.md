# Mô Hình Sinh Câu Hỏi T5-Base (CoQA)

## Hướng dẫn cài đặt trên Windows (Local VS Code):
1. Cài đặt Python 3.10+
2. Tạo môi trường ảo: `python -m venv venv`
3. Kích hoạt venv: `.\venv\Scripts\activate`
4. Cài đặt thư viện: `pip install -r requirements.txt`
5. Import và gọi hàm `generate_question` từ file `inference.py` để sử dụng!
